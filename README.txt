FOOTBALL MANAGER - como rodar
1. Instale o XAMPP e inicie Apache e MySQL.
2. Copie esta pasta para C:\\xampp\\htdocs\\football_manager
3. Abra http://localhost/phpmyadmin > Importar > escolha database.sql > Executar.
4. Se seu MySQL tiver senha, ajuste config.php.
5. Acesse http://localhost/football_manager/ , crie uma conta e use o sistema.
